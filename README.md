# Relay Desk releases

Installers for **Relay Desk** (binaries only; the source code is private).

- Download the latest `Relay-Desk_X.Y.Z_x64-setup.exe` from [Releases](../../releases/latest).
- The app needs a licence key issued for the machine it runs on: without one it starts locked and does nothing.
- Installed apps update themselves from `latest.json` of the latest stable release. Releases marked *pre-release* (`-rc`) are for testing by hand and are never offered to installed apps.
- Each release has a `.sha256` and a `.sig` (the updater's signature) next to the installer.
